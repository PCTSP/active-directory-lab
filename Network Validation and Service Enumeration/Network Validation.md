## Network Validation and Service Enumeration

Objetivo:
Validar conectividade entre as máquinas do laboratório e identificar serviços expostos pelo Domain Controller.

Ferramentas:
- Nmap
- Ubuntu Linux
- Windows Server

Atividades realizadas:
- Configuração de rede Host-Only
- Validação de conectividade entre VMs
- Enumeração de serviços utilizando Nmap

Serviços identificados:
- DNS (53)
- Kerberos (88)
- LDAP (389)
- SMB (445)
- LDAPS (636)
- Global Catalog (3268)

Aprendizados:
- Comunicação entre VMs
- Troubleshooting de rede
- Enumeração básica de serviços
- Reconhecimento de infraestrutura Active Directory
